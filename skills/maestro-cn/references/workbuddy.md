# workbuddy 接入说明

workbuddy 若有 API / CLI 接口，可在 maestro-cn 中作为「外部 CLI 工具」类型的智能体接入，与其他 LLM 智能体一样参与单聊、群聊和自动执行。

## 配置方式

1. 应用「智能体」页 → 新建智能体 → 类型选「外部 CLI 工具（workbuddy）」。
2. 填写**命令模板**：用 `{prompt}` 占位符表示将要交给 workbuddy 的指令文本，例如：
   ```
   workbuddy run --task "{prompt}"
   ```
   （按实际安装的 CLI 命令填写；未安装时可用任意可执行命令体验流程）
3. 可指定**工作目录**（workdir），命令将在该目录下执行；不填则继承后端进程目录。
4. 保存后即可像普通智能体一样被调度。

## 运行机制

- 后端 `backend/workbuddy.py` 用子进程方式执行命令模板，把 `{prompt}` 替换为实际指令，超时上限 600 秒。
- 命令的 stdout 作为智能体回答返回（追加 token 估算与费用记录）。
- 调用失败会以 `（咨询失败：...）` 形式反馈给对话流，不中断整体流程。

## 注意事项

- 命令模板属于**外部指令执行**：只应对可信任的 workbuddy 接口；不要填入含敏感操作（删除、发布、转账等）的命令模板，除非明确授权。
- 当前适配器为通用 CLI 占位实现；若 workbuddy 提供结构化 API（JSON/OpenAPI），可扩展为 HTTP 调用方式。
- 设置页「workbuddy」区有启用开关与参数位，等待具体接口文档后补充。
